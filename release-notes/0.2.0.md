## 更新内容

- **剪贴板历史**：支持文字、图片、文件和更多粘贴格式，提供图片文字 OCR 搜索与应用排除设置。
- **拷贝屏幕文字**：框选屏幕后离线识别中英文或二维码，可选择是否读取二维码、是否移除换行。
- **开发工具与 JSON 美化**：新增独立启用开关和刘海工具卡片，支持格式化、压缩、转义、校验、排序、Unicode 编解码、URL 解码、嵌套解析、字段提取、节点编辑及文件导入导出。树形视图支持折叠和搜索，表格按数据结构展示；保留长整数精度，记住置顶状态。
- **日历与笔记**：日历支持独立页面和周日程导航；笔记支持 Markdown 预览、任务清单与预览内勾选。
- **外观与设置**：新增浅色、深色、跟随系统的刘海外观，以及可选的收起态音乐外围进度；优化媒体和计时器预览，整理设置分组和权限入口。
- **状态与兼容性**：新增输入法显示与切换、电池满环阈值和本机 IP 展示；改进显示器 DDC 音量回读、桌面信号输入、HUD 对比度和设备选择器外观，修正 Codex 额度窗口识别并更新模型价格数据。

JSON 工具在本地处理，单次内容上限为 2 MB；离线 Schema 校验支持常用规则子集，不支持的关键字会明确提示。本版未接入 AI 云端处理。

## 选择安装包

需要 **macOS 14.6 或更新版本**，支持无刘海屏幕和外接显示器。

| 你的 Mac | 下载文件 |
| --- | --- |
| Intel 处理器 | [Eave-0.2.0-Intel.dmg](https://github.com/k1ngr4m/eave/releases/download/v0.2.0/Eave-0.2.0-Intel.dmg) |
| Apple M 系列芯片 | [Eave-0.2.0-AppleSilicon.dmg](https://github.com/k1ngr4m/eave/releases/download/v0.2.0/Eave-0.2.0-AppleSilicon.dmg) |

在苹果菜单 → 关于本机中查看处理器或芯片。打开 DMG，将 Eave.app 拖到“Applications（应用程序）”快捷方式，并替换旧版本。

`Eave-0.2.0.zip` 是双架构通用包，供应用内自动更新使用，也可手动安装；`appcast.xml` 无需手动下载。更新 ZIP 使用 Eave 的 Ed25519 密钥签名。

沿用 0.1.2 的本地 ad-hoc 签名，**未经过 Apple 公证**。首次启动如被系统拦截，尝试打开后前往“系统设置 → 隐私与安全”，选择“仍要打开”。

Intel 版不支持内置的 Apple Silicon 专用直接 DDC 音量控制；其他硬件读数取决于设备支持情况。
